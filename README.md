# lr-grep

这是一个使用 C 语言实现的简易 grep 工具，可以在文件中查找指定的字符串。

欢迎 **Star、Fork 并克隆到本地**以执行！

## 1. 项目结构

```
lrg_Jacky/
├── experiments/    # 开发过程中的实验代码，不影响最终功能
├── main/           # 主程序源码及可执行文件
└── testfiles/      # 测试文件
```

## 2. 运行

仓库中已经包含编译好的可执行文件，克隆到本地后可以直接运行，无需重新编译。

```
./main/lrg
```

如果提示没有执行权限，可以运行：

```
chmod +x main/lrg
```

若实在出现奇怪问题也可以重新编译 `lrg.c`

## 3. 使用方法

```
./main/lrg [选项] PATTERN [FILE...]
```

* `PATTERN`：要查找的字符串。
* `FILE`：要搜索的文件，可以指定多个文件。
* 不指定文件时，从标准输入读取。
* `-n`：显示匹配内容所在的行号。
* `-i`：忽略英文字母大小写。
* `-c`：只输出匹配的行数。
* 支持组合选项，例如 `-ni`。

## 4. 使用示例

在项目根目录下执行。

**查找字符串：**

```
./main/lrg zzh testfiles/findtest.txt
```

**显示行号并忽略大小写：**

```
./main/lrg -ni zzh testfiles/findtest.txt
```

输出示例：

```
1: zzh ttkx!
2: zzh ttkx!
3: zzh ttkx!
4: zzh ttkx!
5: zzh ttkx!
8: ZZH ttkx!
```

**统计匹配行数：**

```
./main/lrg -c zzh testfiles/findtest.txt
```

**同时搜索多个文件：**

```
./main/lrg -ni zzh testfiles/readtest.txt testfiles/findtest.txt
```

## 5. 实现说明

程序使用 `open()` 和 `read()` 读取文件，逐行查找匹配内容，不会一次性将整个文件读入内存。

程序会根据当前行的长度动态调整缓冲区大小，因此内存占用主要取决于最长的一行。

字符串匹配采用简单的逐字符比较，不支持正则表达式。`-i` 选项只处理 ASCII 英文字母的大小写。

## 6. 错误处理


| 错误情况                           | 当前错误提示                          | 返回码 |
| ---------------------------------- | ------------------------------------- | ------ |
| 缺少`PATTERN`                      | `usage: lrg [-nic] PATTERN [FILE...]` | `2`    |
| 出现未知选项字符，例如`-x`、`-nix` | `usage: lrg [-nic] PATTERN [FILE...]` | `2`    |
| `open()` 打开文件失败              | `lrg: 文件名: 错误原因`               | `2`    |
| `read()` 读取文件失败              | `lrg: 文件名: 错误原因`               | `2`    |
| `malloc()` 分配内存失败            | `lrg: 文件名: 错误原因`               | `2`    |
| `realloc()` 扩容失败               | `lrg: 文件名: 错误原因`               | `2`    |
| 存在匹配且未发生错误               | 无错误提示                            | `0`    |
| 没有匹配且未发生错误               | 无错误提示                            | `1`    |

## 7. 已知限制

* 只支持 `-n`、`-i`、`-c` 三个选项。
* 不支持正则表达式，只能查找普通字符串。
* 忽略大小写时，只处理 ASCII 英文字母。
* 部分极端情况和输出错误可能尚未完善处理，期待读者检验发现。
